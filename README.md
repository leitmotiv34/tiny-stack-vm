A stack VM in TypeScript (Node 22, standard library only) for make.fun's
tiny stack ISA v1: 32-bit wrapping arithmetic, exact trap exit codes, the
step and output limits. Answers every instance with stdout.bin and
exit.txt. Deterministic.
